## نسخه PDF

`ketapod-tech-spec.pdf` نسخه چاپی بخش‌های ۰۳ و ۰۴ است، برای وقتی که باید سند را
به کسی بیرون از تیم بدهی. سورس لاتک کنارش هست.

```bash
tectonic -X compile ketapod-tech-spec.tex
```
